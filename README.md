Чат-сервер на C++
Многопоточный чат-сервер с базой данных MySQL. Поддерживает публичные/приватные сообщения, регистрацию пользователей, административную панель и систему банов.

Основные возможности
Для пользователей:

- Регистрация и авторизация (пароли хешируются SHA1)
- Приватные и публичные сообщения
- Просмотр списка пользователей с онлайн-статусом
- История сообщений

Для администраторов:

- Просмотр всех/онлайн/забаненных пользователей
- Блокировка/разблокировка пользователей
- Удаление пользователей

Технические требования:

C++17, CMake 3.10+
База данных (MySQL) 
Linux/Unix (используются POSIX сокеты)

База данных:

MySQL с базой bd
Пользователь: dbeaver, пароль: dbeaver123 (Можно изменить под себя на 12 строке файла Chat.cpp)

Таблицы создаются автоматически

Установка: 
Зависимости (Ubuntu/Debian):

sudo apt-get install g++ cmake libmysqlcppconn-dev libmysqlclient-dev libssl-dev
Настройка БД:

CREATE DATABASE bd;
CREATE USER 'dbeaver'@'localhost' IDENTIFIED BY 'dbeaver123';
GRANT ALL PRIVILEGES ON bd.* TO 'dbeaver'@'localhost';
Сборка:

mkdir build && cd build - делается в директории проекта
cmake .. && make
Запуск:

./Chat_Server
Сервер слушает порт 7777.

Протокол команд
Формат: <код_команды> [параметры]

Архитектура:
Chat - основной серверный класс, управление соединениями

DatabaseManager - работа с MySQL, хеширование паролей

ThreadPool - пул для обработки клиентов

User/Message - модели данных

Особенности реализации:
Потокобезопасность: shared_mutex для пользователей, мьютексы для БД

Неблокирующие сокеты с буферизацией команд

Атомарный логин (защита от двойных сессий)

Копирование данных при сетевых операциях для минимизации блокировок

Структура БД
Таблицы:

users - id, name, login, password, is_banned

public_messages - публичный чат

private_messages - приватные сообщения

Администраторы
Настраиваются в коде (Chat.h):

{"admin", "admin123"},
{"moder", "moder123"}
Ограничения:
Максимальная длина сообщения: 4096 байт

История публичного чата: 50 последних сообщений

Одновременно активных соединений: до 50

Одна сессия на пользователя

Проблемы:
1. Странная проблема с публичными сообщениями: Если сначала написать что-то в чат, а затем прочитать то сервер закроет соединение.
2. Методы админ панели напрочь отказываются работать
3. Чат ломается при 2+ пользователях, хотя я всеми силами пытался организовать многопоточность.
