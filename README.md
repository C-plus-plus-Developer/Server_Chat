# Chat_Server
Консольный чат-сервер, написанный на С++ под UNIX систему. Ссылка на клиента: https://github.com/C-plus-plus-Developer/Chat_Client.git 
Все данные хранятся в базе данных. Чтобы подключиться к своей бд, введите нужные данные в 18 строке файла Chat.h. Сейчас там указаны данные для подключения к моей бд MySQL.
Программа сама создает необходимые таблицы, не нужно париться на этот счет. Также я немного переделал функцию хеширования sha1, благодаря чему пароль стал еще более защищенным.
PS: почему-то когда клиент выходит из пользователя и хочет к примеру войти или зарегаться снова, введенные им данные сохраняются в публичные сообщения(жосткая подстава), не знаю с чем это связано, вроде клиент и сервер нормально прописан.
